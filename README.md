# Nexora Technologies Website

Premium single-page application for a fictional technology company.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- React Router
- Motion (Framer Motion)
- Lucide React

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Content

All site copy lives under `src/data/` so branding and content can be updated without an admin panel.
